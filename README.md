# DEVCONF 2026 - лендинг IT-конференции на Vue.js

Лабораторная работа № 21. Построение интерфейса веб-приложения на Vue.js
с использованием экземпляра Vue, компонентов и директив.

Вариант 2: лендинг IT-конференции. UI-компоненты перенесены в код
из дизайн-системы, спроектированной в лабораторной работе № 17.

## Стек

- Vue 3, Options API, однофайловые компоненты
- Vite 5 как сборщик и сервер разработки
- Инкапсуляция стилей атрибутом `scoped`

Библиотеки управления состоянием (Vuex, Pinia) не используются: данные
хранятся в опции `data()` компонентов и передаются через `props`
и пользовательские события.

## Требования

- Node.js версии 18 или новее
- npm версии 9 или новее

## Запуск

```bash
git clone <адрес репозитория>
cd devconf-vue
npm install
npm run dev
```

Vite выведет в терминал адрес локального сервера, по умолчанию
http://localhost:5173, и откроет его в браузере.

## Остальные команды

```bash
npm run build     # production-сборка в каталог dist
npm run preview   # локальный просмотр собранной версии
```

├── App.vue                      корневой компонент

## Компоненты

| Компонент | props | data() | Методы и события |
|---|---|---|---|
| `App` | нет | `speakers`, `registrations`, `tagline`, `details` | `handleRegister()`, `formatLabel()` |
| `SpeakersList` | `speakers` (Array, required), `title` (String) | `expandedIds` | `handleToggle()`, computed `expandedCount` |
| `SpeakerCard` | `speaker` (Object, required, с валидатором) | `areDetailsVisible` | `toggleDetails()`, computed `toggleLabel`, событие `toggle` |
| `RegistrationForm` | `title`, `submitLabel` (String) | `name`, `email`, `format`, `acceptsNews`, `errors` | `validate()`, `submit()`, `reset()`, событие `register` |

## Использованные директивы

- `v-for` с обязательным `:key` - список спикеров и список зарегистрированных участников
- `v-if` / `v-else-if` / `v-else` - бейдж формата участия, раскрытие подробностей о спикере, тексты подсказок и ошибок, пустые состояния списков
- `v-model` - поля формы регистрации, включая `v-model.trim` для текстовых полей, `select` и `checkbox`
- Сокращённые формы `:` и `@` вместо `v-bind` и `v-on`, включая модификатор `@submit.prevent`

## Что можно проверить в интерфейсе

1. Клик по ссылке «Подробнее о спикере» раскрывает биографию и уровень доклада,
   подпись ссылки меняется. Счётчик раскрытых карточек в подзаголовке секции
   обновляется: карточка сообщает о переключении событием `toggle`.
2. Бейдж формата участия отличается у офлайн- и онлайн-спикеров.
3. Отправка формы с пустым именем или некорректным адресом подсвечивает поля
   и выводит сообщения об ошибках.
4. Корректная отправка добавляет участника в список справа: форма генерирует
   событие `register`, корневой компонент принимает его и пополняет массив.

## Связь с ЛР № 17

Цвета, типографика, радиусы, отступы и тени вынесены в `src/assets/styles.css`
в виде CSS-переменных, имена которых повторяют имена стилей Figma.
SVG-иконки, логотип и изображения взяты из набора ассетов той же работы.
